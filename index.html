Before you start

Recommended learning setup

You can read every page without installing anything. For practice, use a code editor such as VS Code, a current Node.js LTS release, Python 3, Git, and a terminal. Install Rust with rustup only when you reach Tauri; the official Tauri prerequisites page lists operating-system-specific dependencies. SQLite can be used through Python at first; a command-line client is a useful extra.

Keep one practice folder with small experiments. Do not start by wiring together the entire stack. First make a static screen, then add React state, then a single endpoint, then persistence.

One architecture fact worth remembering

Tauri does not automatically run a FastAPI server or connect React to SQLite. In a Tauri app the frontend runs in a webview and Rust owns privileged desktop operations. If you keep FastAPI, treat it as a separate local service/sidecar whose startup, shutdown, network binding, and packaging must be designed. Chapter 10 compares that with using Rust commands and SQLite directly.

How to study

Learn in loops, not in a marathon

  1. Read one section and predict what the code will do.
  2. Type it yourself and run it; change one value and observe what changes.
  3. Explain each value’s shape: number, string, object, array, or response.
  4. Do the exercise before reading the answer guidance.
  5. Build one small feature end-to-end, then ask AI to explain code you do not understand.

Expect several weeks of practice, not a single weekend, if you are learning the tools as well as the language. You can begin your MVP before you know every chapter: finish Chapters 1–7, then work through 8–11 just in time.

A note on scope

What “learn properly” means here

This course teaches the core concepts used in a small data-driven desktop feature. It is not a complete computer-science curriculum, full Rust course, production security guide, or specification for any particular business domain. The references at the end of lessons are there for deeper practice. Use them after you can explain the examples in your own words.
