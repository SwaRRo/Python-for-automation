# Python Backend & Automation

This is the standalone, static HTML course: one landing page plus 15 linked chapters. It includes the shared CSS, JavaScript, and course-mark assets required by those pages. The Tauri course is intentionally not included in this archive.

## Run locally

Extract the ZIP, open a terminal in this folder, and run:

```bash
python3 -m http.server 8000
```

Then visit <http://localhost:8000/>. A small static server is recommended so that chapter navigation, theme preference, and browser progress work consistently. No Python packages or application backend are required to read the course. The references at the end of lessons link to external documentation and need internet access.
