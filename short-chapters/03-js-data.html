JavaScript values and data structures

JavaScript is the language that gives the interface behavior. Start by learning how to name values and organize data into records and lists.

Estimated time: 35–50 minRead, type, explain, practice
Concise version. This preserves the earlier, shorter lesson. Open the expanded Chapter 03 lesson for the full walkthrough.

By the end, you can…

  • Choose between const and let.
  • Recognize primitive values, objects, arrays, null, and undefined.
  • Read and update an object representing an app record.

Variables and types ¶

A variable is a name bound to a value. Prefer const; use let only when you will reassign the binding. JavaScript’s common primitive types include string, number, boolean, undefined, null, bigint, and symbol. You will mostly use strings, numbers, booleans, and the special missing-value cases in app code.

const title = "Prepare report";   // string
const priority = 2;               // number
let isDone = false;               // boolean
isDone = true;                    // reassignment is allowed with let
const dueDate = null;             // explicitly no date yet
let serverResult;                 // undefined until assigned

A const variable cannot be assigned a different value, but if it holds an object, the object’s properties can still be changed. That distinction matters later in React; we usually create a new object and array instead.

Objects represent one record ¶

An object groups named properties. It is similar to a Python dictionary. Use dot notation when you know the property name, and bracket notation when it is computed or contains special characters.

const task = {
  id: 7,
  title: "Prepare report",
  priority: 2,
  done: false,
};

console.log(task.title);     // "Prepare report"
task.done = true;            // property mutation (avoid this for React state)

JavaScript object properties are often accessed with dot notation; object literals use braces. Python dictionaries use square-bracket lookups by default.

Arrays are ordered collections ¶

An array stores values in order and starts counting positions at zero. An app’s records commonly arrive as an array of objects.

const tasks = [
  { id: 7, title: "Prepare report", done: false },
  { id: 8, title: "Book a room", done: true },
];

console.log(tasks.length);       // 2
console.log(tasks[0].title);     // "Prepare report"

Arrays and objects are reference values: variables point to them. Two variables can refer to the same underlying object. That is why changing a shared nested value can create surprising effects. For React UI state, prefer a new array/object when representing a change.

JSON resembles object/array syntax, but JSON is text with stricter rules. Chapter 5 explains the conversion boundary.

Read types before values

If code fails, ask: is this value a string, a number, an object, or an array? A string "3" is not the same thing as number 3.

Practice it

Create an object for a book, note, task, or product with an ID, a name/title, a numeric field, and a boolean status. Put two such objects in an array. Read one property from the second object.

Show answer guidance

For example: const notes = [{id:1,title:"Idea",pinned:false},{id:2,title:"Meeting",pinned:true}]. The second title is notes[1].title. The array index is 1, but its item ID is 2; those are different concepts.
